# 🇦🇷 KukaTrap

Desarrolado en Python - Usando la libreria PygBag


**Evita que los Kukas te copen los distritos**
Un juego arcade hecho en Pygame donde tenés que proteger las 24 provincias argentinas de la invasión.


---

### Cómo se juega

- **Clic en un Kuka (Bill)** → lo eliminás (+50 puntos)
- **Arrastrá el balde** sobre un distrito infectado (rojo) → lo sanás (+150 puntos)
- Sobreviví el mayor tiempo posible y subí de nivel

---

### Controles

| Acción                    | Control              |
|---------------------------|----------------------|
| Eliminar Kuka             | Clic izquierdo       |
| Sanar distrito infectado  | Arrastrar el balde   |
| Empezar                   | Enter                |
| Reiniciar                 | R                    |
| Salir                     | ESC                  |
